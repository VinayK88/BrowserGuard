# Methodology

BrowserGuard uses deterministic synthetic extension profiles. The score combines permission sensitivity, publisher trust, permission drift, update-channel state, session/cookie exposure, external posting, OAuth/SaaS reach, AI-context handling, behavioral deviation, and user reach.

Thresholds are project heuristics, not calibrated probabilities. The baseline exists to make decision logic reproducible and reviewable. Production evidence should come from authorized managed-browser, identity, SaaS, and security telemetry sources.
